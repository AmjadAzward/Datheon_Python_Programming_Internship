**Description:**

Completed four Python projects during the Datheon Python Programming Internship: Hangman, Investment Portfolio Tracker, Advanced File Organizer, and Customer Support Chatbot. I also created a responsive live showcase with interactive browser demonstrations.

The Hangman demo includes three difficulty levels, hints, replay support, ASCII graphics, and win statistics. The portfolio tracker supports adding, editing, and removing holdings, profit/loss calculations, performance rankings, local data persistence, and CSV export. The file organizer provides file categorization, drag-and-drop support, dry-run previews, undo operations, and statistics. The chatbot handles FAQs, greetings, help requests, feedback ratings, chat exit commands, and conversation history.
