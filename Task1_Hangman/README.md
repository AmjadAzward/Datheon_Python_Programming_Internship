
# Hangman Game

A terminal-based Hangman game developed using Python as part of the Datheon Python Programming Internship.

## Features

- Three difficulty levels: Easy, Medium, and Hard
- Random word selection
- Multiple word categories
- ASCII Hangman graphics
- Hint system
- Input validation
- Duplicate letter detection
- Replay functionality
- Game statistics
- Win percentage calculation
- External word list support

## Technologies Used

- Python 3
- Random module
- Pathlib module
- Visual Studio Code

## Installation and Execution

### Requirements

Python 3 must be installed on your computer.

### Run the Game

1. Download or clone this repository.
2. Open the Task1_Hangman folder in VS Code.
3. Open the terminal.
4. Execute the following command:

```bash
python3 hangman.py
```

## How to Play

1. Select your preferred difficulty.
2. A random secret word will be selected.
3. Guess the hidden word one letter at a time.
4. Use the hint feature when needed.
5. Avoid incorrect guesses to win.
6. Choose whether to play again.
